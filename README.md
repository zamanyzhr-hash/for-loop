Brief Description  
A simple C# console application that prints star patterns (ascending and descending).

## 🛠️ Technologies / Tools  
- C#  
- .NET Console App

## ✅ What this project does  
- Prints an ascending star pattern  
- Then prints a descending star pattern  

## 📥 How to Run / Use  
1. Clone the repository or download ZIP  
2. Open in Visual Studio (or your preferred C# IDE)  
3. Build and run — console window will display the star patterns  

## 📁 Project Structure  
- Program.cs → main code  

## 📌 Notes / Limitations  
- No external dependencies  
- Simple console-based demonstration
